## ✨ A tree that feels alive

**Tree Petals Drop** transforms a Framer frame into a dreamy, motion-rich scene. Delicate flowers cluster on procedural branching forms while petals drift through the atmosphere. Fine-grained controls let you tune the composition, breeze, lighting, and cursor interaction to suit your design.

Built as a single **React + TypeScript Framer Code Component**, it requires no external image assets.

> Designed and created by **Karim Saif**. Made with 💛.

## 🌳 Five distinct tree presets

| Preset | Mood |

| 🌸 **Sakura** | Dreamy pink cherry blossoms and rosy ambience |
| ✨ **Golden** | Warm amber light and glowing golden flowers |

## ⚡ Features

- **Procedural flowering tree:** Branch shapes, clustered blossoms, and hanging sprays are generated in code.
- **Thousands of blossoms:** Tunable density, size, clumping, and twig details.
- **Natural petal fall:** Adjustable number, wind, drift, wobble, and falling speed.
- **Five visual themes:** Moonlit, Ice Tree, Sakura, Golden, and Midnight.
- **Cursor interaction:** Optional cursor reaction with adjustable strength.
- **Cinematic atmosphere:** Haze, depth of field, highlight, grain, vignette, and bokeh controls.
- **Responsive Framer frame:** The canvas adapts to your section's size.
- **Motion awareness:** Reduced-motion behavior and animation pausing for offscreen or hidden content.
- **Performance controls:** Device pixel ratio limits and graphics-resource cleanup.
- **No image dependencies:** Procedural artwork and native canvas/WebGL rendering.

## 🧩 Install in Framer

1. Open your project in **Framer**.
2. In **Assets → Code**, create a **Code Component**.
3. Open [`KarimSaifTreePetalsDrop.tsx`](./KarimSaifTreePetalsDrop.tsx) and copy its entire contents into the component file.
4. Save the component and drag **Karim Saif Tree Petals Drop** onto the canvas.
5. Resize the frame, pick a preset, and adjust its properties in the right sidebar.

**Requirements:** Framer Code Components, React, and TypeScript support. No additional package installation is required by this component.
